## Installation Guidelines

Follow these steps to set up the server locally:

### Prerequisites
- **Node.js** (>= 18.x recommended)
- **npm** or **yarn**
- **ffmpeg** (must be installed and added to system PATH)

### Install Dependencies
``` bash
npm install
```
### Install ffmpeg
```bash
sudo apt install ffmpeg
```
